# Steam 助手速查

本技能说明如何使用 **steam_manager** 插件协助用户管理 Steam 与游戏。

## 能力一览

| 操作 | 触发词示例 | 说明 |
|---|---|---|
| `status` | Steam 开着吗 / 装在哪 | 客户端状态与安装路径 |
| `list` | 我 Steam 里有什么游戏 | 本地库列表（名称过滤/条数上限） |
| `launch` | 打开/启动 <游戏> | 需精确名称或 AppID；重名给候选 |
| `capture` | 现在游戏什么情况 / 截个图 | 前台游戏窗口截图（BMP/PNG 路径） |
| `watch` | 帮我盯着游戏 | 后台周期截帧 + 行为时间线 |
| `summary` | 这局进展如何 | 局面汇总：监控/接管/最近画面/行为记录 |
| `control` | 让 YUI 接管 / 你来玩 | **键鼠接管，必须用户显式授权，默认关闭** |
| `action` | （接管后）点击/按键/输入 | 仅作用于已授权的前台游戏窗口 |

## 纪律

### 安全边界（硬性）
- 接管默认关闭；开启前必须已有最近窗口画面（先 capture 或 watch）
- 接管只作用于当前前台游戏窗口，不读取账号与凭据
- 用户随时说「停止接管」即交还

### 流程
1. 启动游戏前先确认库中已安装（list 或 launch 自校验）
2. 需要了解局面时：capture 截一帧 → 视觉能力看图 → 给出建议
3. 持续跟进时：watch 开启 → summary 汇总 → 有变化才播报，不重复刷屏
4. 代打时：control on 需用户明确授权 → action 逐次操作 → 每步记录到时间线

### 常见问题
- 「看不到画面」：确认游戏窗口在前台（最小化会截不到）
- 操作无效：检查接管是否开启、窗口最近 15 秒内是否有新画面
- 误操作风险：每次 click/key/text 前确认目标坐标与内容
