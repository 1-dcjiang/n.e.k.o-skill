# B站协作指南

本技能说明 YUI 如何正确使用 **bili_viewer** 插件协助用户浏览与管理哔哩哔哩。

## 核心能力

| 需求 | 操作 |
|---|---|
| 搜索视频/直播/用户 | 搜索工具，关键词传入 |
| 查看视频详情 | 标题/UP主/时长/播放/弹幕数/分P/标签/评论/CC字幕/AI概要 |
| 直播间信息与实时弹幕 | 直播工具（匿名采集） |
| 感知用户当前观看 | 前台窗口感知：识别 B站视频/直播自动匹配详情 |
| 发弹幕/直播回复 | 需绑定 B站登录态（浏览器扩展直连，CDP 运行时接入） |

## 流程与纪律

### 搜索与详情
1. 用户给出关键词 → 搜索 → 命中后展示标题+UP主+数据摘要
2. 用户选定 → 查详情/评论/字幕，按需汇报

### 感知当前观看
- 用户说「我在看X」或需要上下文时，用感知工具读取当前窗口
- 若窗口是 B站视频/直播 → 自动匹配并给出标题、UP主、在线人数/播放量
- **看不到实时画面时**：明确说明「只能拿到标题/在线人数等元数据，看不到画面」，不要假装看见

### 弹幕与直播回复（写操作）
1. **前置**：必须已绑定登录态（浏览器扩展直连，无需手动复制 Cookie）
2. 发弹幕：确认目标（视频 BV 或直播间房号）+ 文案，一次发一条
3. **不要重复发送**：同一弹幕内容在短时间窗口内只发一次（幂等去重）
4. 发送结果以插件实际返回为准，失败如实说明原因（如被过滤/风控），不要谎称成功

### 用户隐私
- 登录态 Cookie 仅本地使用，不上传、不写入日志
- 不读取用户未授权的账号敏感信息

## 常见问题

- 弹幕发不出去 → 检查是否绑定登录态、是否开启弹幕过滤（只看主播/只看高能会把普通弹幕过滤掉）
- 「显示发了但看不到」 → 先检查弹幕过滤设置，再检查是否发送到错误的房间
- YUI 反复播报 → 短时间同一事件只播报一次，避免话术重复
